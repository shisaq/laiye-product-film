# Laiye Worker

## 名称和定位

- 写法：**Laiye Worker**；中文片里可写"来也 Worker"。不写 LaiyeWorker（话题标签除外）、Laiye worker。
- 图标：`../../logos/laiye-worker.png`（黄色笑脸，深色圆角方底）。
- 一句话：桌面端 AI 员工平台。从 Marketplace 添加一位 AI 员工（Worker），在一次对话里把它配置好，之后它跨系统完成工作，关键决定留给人确认。
- 系统：macOS 与 Windows 双平台（用户确认，2026-10-26）。
- 下载：来也科技官网。

## 可以上画面的事实

| 事实 | 出处 |
|---|---|
| 左侧栏：标题 Laiye Worker、搜索会话、会话列表（头像 + 名称 + 时间 + 最后一句）、底部 Marketplace、账号（Personal edition） | 录屏 2026-10-23，`reference/02`、`05` |
| Marketplace 是弹窗：Worker 标签页、Featured 深色卡片、黄色 **+ Add**、**Details →** | `reference/01` |
| 配置在对话里完成：AI 员工提问，下面是带字母的选项卡（A / B / C…），可以自由输入，**Submit** 提交；答过的卡片折叠成一行带 ✓ | `reference/03`、`04` |
| 执行时出现分步清单："On step 1 of 6"，当前步是蓝色实心圆，未做的是虚线圆 | `reference/05` |
| 结果之后给出带推荐项的选项卡，由人决定下一步 | `reference/06` |
| AI 员工在云端运行，电脑合上也能继续（24/7） | 产品方说明，2026-10（AP Highlight 简报） |

不能说：AI 员工替人审批或付款；任何录屏里没出现过的按钮、菜单、模式名。

## 界面结构（重绘用）

```
┌───────────────┬──────────────────────────────────────────────┐
│ Laiye Worker  │        ( 头像  AI 员工名称 )   [会话图标]     ─ □ ✕ │
│ [搜索会话]     │                                                  │
│ ● 会话 1  时间 │   AI 消息气泡（浅灰底，圆角 14）                    │
│ ○ 会话 2       │   ┌ 问题标题（粗体）                        ┐       │
│               │   │ [A] 选项一                    Recommended │       │
│               │   │ [B] 选项二                               │       │
│               │   │ [自由输入框]                  [Submit]    │       │
│               │   └──────────────────────────────────────────┘       │
│ Marketplace   │                         用户消息（米色胶囊，靠右）  │
│ 账号 / 版本    │ [+] [Message <AI 员工名称>                     ]  │
└───────────────┴──────────────────────────────────────────────┘
```

- 颜色：`ui-tokens.json`（浅色取自 2026-10-23 录屏，深色取自 2026-09-04 录屏）。
- 字体：界面是系统字体；英文界面用 Inter 重绘，中文界面用思源黑体。正文约 17px，侧栏标题约 23px（以 1828×1080 录屏为基准）。
- 圆角：气泡 14px，选项组 9px，用户消息胶囊 20px，窗口 10px。
- 可直接参考的重绘代码：`examples/ap-highlight-v03/ui.js` 和 `index.html` 的样式（浅色主题，含侧栏、对话、选项卡、清单、Marketplace）。**只借技术，不照搬它的画面和结构。**

# BRIEF · __TITLE__

> 简报只回答"做什么、给谁、用什么素材、有什么限制"，不写怎么拍（那是 TREATMENT）。填不出来的项，在一轮提问里问用户；能自己定的给默认值并写明"（默认）"。

## 基本

| 项 | 值 |
|---|---|
| 一句话目的 | 例：让第一次看到的人 45 秒内明白它能端到端做完 AP，然后去下载试用 |
| 核心句 | 片子要让人记住的一句话（产品方给的原话） |
| 受众 | 谁、懂多少、在乎什么；看之前知道什么、不知道什么 |
| 看完以后 | 知道 ___；相信 ___；去做 ___ |
| 误读风险 | 观众可能误会的地方（例：以为每封邮件都要手动配置；以为 AI 会自动付款） |
| 渠道与用途 | LinkedIn / X / YouTube / 视频号 / 官网 / 展会大屏 / 销售演示 / 剪进另一条片子 |
| 时长 | 例：45–60 s |
| 画幅 | 1920×1080（默认）/ 1080×1920 / 1080×1350 |
| 语言 | __LANG__（画面文字）；是否要另一语言版本 |
| 声音 | 只有音乐和音效（默认）/ 旁白 + 字幕 / 用户自带配音 |
| 风格 | __STYLE__（理由一句） |
| 帧率与交付 | 30 fps H.264（默认）；要剪进 25p 工程就 25 fps；是否要透明叠层 |
| 审核点 | 故事线审批（默认要，用户明确说不用才跳过）；是否另看分镜（默认否）；谁审 |
| 截止 | |
